# Does More Crop Production Mean Less Hunger? (Analysis of Crop production vs Food security in Africa, 2010–2024)

## Introduction
This project investigates whether increased crop production guarantees improved food 
security across Africa. It was completed as part of the Data Analytics Program at 
WETIN DEY ACADEMY, using crop production and food security data from Food and Agriculture Organization Statistical Database (FAOSTAT), analysed in Microsoft Power BI.

## Objectives
1.	To examine trends in crop production and food security (undernourishment) across Africa between 2010 and 2024
2.	To assess the relationship between production growth and undernourishment (food security indicator) at the country level 
3.	To compare patterns between production growth and undernourishment (food security indicator) across Africa's five regions.
4.	To evaluate, based on the findings above, whether the data supports that increased crop production guarantees improved food security in Africa.
   
## Insights
- Africa's total crop production rose by 53% between 2010 and 2024, while average 
  undernourishment ended the period higher than where it started i.e. 18.21 - 18.59%
- 21 of 48 countries, increased production while undernourishment 
  stayed flat or worsened, i.e. food security did not improve.
- 5 countries improved food security despite falling production.
- Central and Southern Africa showed opposite patterns, with Central Africa 
  emerging as the region furthest from the "more food, less hunger" assumption.

## Conclusion: 
Increased crop production does not guarantee improved food security in Africa — production is one contributing factor among several factors.
